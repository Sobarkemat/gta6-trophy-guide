Leonida Platinum — an offline web app that is the guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a checklist saved in your browser, export and import, filters, a spoiler setting, a roadmap to the platinum, and a guide to each trophy in our own words with sources.

## Run it

```sh
node serve.ts # then open http://localhost:8080
```
